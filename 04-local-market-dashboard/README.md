# 04. 상가(상권) 정보 요약 대시보드

🔗 **대시보드 열기:** https://fivcomet.github.io/Elice-AX/04-local-market-dashboard/

소상공인시장진흥공단의 전국 상가(상권) 정보를 정리해 지역·업종별로 집계한 대시보드입니다.
지역을 선택하면 모든 그래프가 그 지역 기준으로 바뀌고, 분석 리포트를 내려받을 수 있습니다.

## 화면 구성

1. **업종별 가게 수:** 대분류 10개 업종
2. **지역별 가게 수:** 16개 시·도
3. **지역 × 업종 비교:** 지역 안에서 업종이 차지하는 비중 히트맵
4. **음식점 세부 종류 TOP 15**
5. **데이터 정리 과정 요약:** 빈 열 삭제, 표기 통일, 중복 제거 등

## 데이터

- 소상공인시장진흥공단 상가(상권)정보 (2026.06), 16개 시·도 파일 통합
- 원본 2,772,484건 → 정리 후 2,740,287건
