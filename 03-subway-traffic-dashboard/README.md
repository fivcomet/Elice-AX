# 03. 서울 지하철 혼잡도 대시보드

🔗 **대시보드 열기:** https://fivcomet.github.io/Elice-AX/03-subway-traffic-dashboard/subway-traffic-dashboard.html

서울 지하철 호선·역별 시간대별 승하차 인원 데이터로 만든 인터랙티브 대시보드입니다.
호선, 역, 시간대, 요일을 선택하면 혼잡도를 확인할 수 있습니다.

## 화면 구성

- **메인:** 선택한 역·요일·시간대의 혼잡도 지수, 예상 이용객, 최대 혼잡 시간대, 전체 역 중 순위
- **시간대별 혼잡도 곡선:** 선택 요일과 다른 요일 비교
- **요일별 혼잡도 비교**
- **역 × 시간대 히트맵:** 노선 전체 역의 혼잡 패턴
- **혼잡 역 TOP 20**
- **월별 이용객 추이 (실측)**

## 데이터

- 서울시 지하철 호선별 역별 시간대별 승하차 인원 정보 (월 집계 CSV)
- 원본에 요일 정보가 없어 **요일·공휴일 값은 가정 기반 추정치**입니다. 가정 내용은 대시보드의 「데이터·가정 정보」 버튼에서 볼 수 있습니다.
- 데이터와 차트 라이브러리(ECharts)가 파일 안에 포함되어 있어 인터넷 연결 없이도 열립니다. 그래서 파일 크기가 약 5MB입니다.
