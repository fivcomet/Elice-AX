[실습] 공공데이터 기반 상권 데이터 정제 및 분석

전국 상가업소 데이터를 Helpy Code에게 맡겨 빈칸과 표기 오류를 정리하고, 그래프와 대시보드로 만들어 봅시다.

정리 기준은 내가 정하고, 손이 많이 가는 정제 작업은 AI에게 맡기는 흐름을 경험합니다.


데이터: 소상공인시장진흥공단 전국 상가업소 정보(업종 코드, 주소, 위도와 경도, 지역별 CSV 파일 16개)

데이터 내려받기 : Practice.zip


1. 데이터 위치 알려 주기

❶ 새 대화를 열고 첫 메시지 보내기

왼쪽 위의 새 대화를 누르고, 아래의 프롬프트로 실습 데이터가 있는 곳을 알려 주세요. 이 실습은 이 대화 하나에서 끝까지 이어 갑니다.

홈 폴더(/home/elicer)의 Practice 폴더에 있는 파일로 작업할 거야.
먼저 그 폴더의 파일 목록을 보여 줘.

목록에 나온 파일이 지역별 CSV 파일 16개인지 확인한 뒤 다음 단계로 넘어가세요.

파일 목록이 나오지 않아요

/mnt/elice/project 폴더도 찾아봐 달라고 요청해 보세요.

그래도 없으면 설명 탭의 링크에서 Practice.zip을 내려받아 메시지 입력란 왼쪽의 + 버튼으로 올리고, 그 파일을 쓰라고 알려 주세요.


2. 데이터 파악하기

파일이 크기 때문에 세종 파일 하나만 먼저 열어 확인해 보세요.

Practice 폴더의 상가(상권)정보 CSV 가운데 세종 파일 하나만 열어서 알려 줘.
1. 가게가 총 몇 개이고, 정보 항목(열)은 몇 개인지
2. 각 항목마다 빈칸이 몇 %인지, 많은 순서대로
3. 업종이 어떻게 분류되어 있는지, 업종별 가게 수
4. 같은 가게가 두 번 들어간 경우가 있는지
5. 위도와 경도 값이 한국 밖을 가리키는 게 있는지
결과를 표로 보여 주고, 각 항목이 무슨 뜻인지 한 줄씩 설명해 줘.
권한 요청이 뜨면 내용을 읽고 허용해 주세요.


3. 데이터 정리하고 합치기

2단계에서 찾은 문제를 아래 기준으로 정리하고, 16개 파일을 하나로 합쳐 달라고 요청하세요.

2단계에서 찾은 문제들을 정리해 줘.
1. '동정보', '호정보' 열은 전부 비어 있으니 지워 줘.
2. '층정보'의 지하는 -1처럼 음수로 바꿔서 전부 숫자로 맞춰 줘.
3. 주소에 지역명이 두 번 반복되면(세종특별자치시 세종특별자치시 어진동) 반복된 부분을 지워 줘.
4. 가게 이름이 '업소명없음'인 것은 이름 없음으로 처리해 줘.
5. 위도와 경도가 한국 범위를 벗어난 가게는 빼 줘.
6. 같은 가게가 중복으로 들어갔으면 하나만 남겨 줘.

그리고 16개 파일을 하나로 합쳐 줘. 파일이 크니까 나눠서 읽어 줘.
마지막에 원래 몇 개였고 정리 뒤 몇 개가 남았는지, 단계마다 몇 개가 걸러졌는지 숫자로 알려 줘.

정리 전과 정리 뒤의 가게 수가 숫자로 나오면 다음 단계로 넘어가세요.


4. 시각화하기

정리한 데이터로 아래 그래프를 그려 줘. 한글이 깨지지 않게 해 줘.
1. 업종별 가게 수
2. 지역별 가게 수
3. 서울에서 가게가 가장 많은 구 15곳
4. 음식점 안에서 많은 세부 종류
5. 서울 가게 위치를 점으로 찍은 지도
각 그래프 아래에 이 그래프에서 무엇을 알 수 있는지 한 줄씩 써 줘.

그래프를 더 보기 좋게 다듬고 싶어요 (선택)

그래프를 더 보기 좋게 고쳐 줘.
- 막대는 큰 값부터 정렬하고 막대 끝에 숫자 표시
- 숫자에 쉼표 넣기 (554092는 554,092로)
- 같은 업종은 모든 그래프에서 같은 색으로
- 지도는 점이 많아 뭉개지니 점을 흐리게 하거나, 가게가 많은 곳일수록 진하게 보이는 지도(밀집도)로 바꾸기
- 제목과 축 이름은 한글로, 테두리는 없애기


5. 대시보드 만들기

정리한 결과를 한눈에 볼 수 있는 웹페이지를 인터넷 없이도 열리는 HTML 파일 하나로 만들어 줘.
- 맨 위: 전체 가게 수, 업종 수, 지역 수를 큰 숫자로
- 정리 과정 요약: 어떤 문제를 어떻게 고쳤고 몇 개가 걸러졌는지 표로
- 그래프 4개: 업종별, 지역별, 지역과 업종 비교, 음식점 세부 종류
- 지역을 고르는 선택 메뉴: 고르면 그래프가 바뀌게
- 오른쪽 위 '분석 리포트 다운로드' 버튼: 지금 고른 지역 기준으로 주요 숫자와 해석이 담긴 문서 저장


6. 결과 확인하기

❶ 답변 아래에 나온 미리보기 버튼을 눌러 대시보드를 확인하세요.

❷ 미리보기 창 위쪽의 바깥 브라우저로 열기 버튼을 누르면 더 크게 볼 수 있어요.

❸ 지역을 바꿔 보고 분석 리포트 다운로드 버튼도 눌러 보세요. 고칠 점은 같은 대화에 하나씩 요청하세요.

미리보기 버튼이 보이지 않아요

서버를 띄우는 방식으로 만들면 http://localhost:8000 같은 주소만 알려 줄 수 있어요. 답변의 주소를 눌러 열고, 열리지 않으면 HTML 파일 하나로 다시 만들어 달라고 요청해 주세요.

미리보기 화면이 좁아요

왼쪽 위의 X 버튼으로 강의 목차를 닫거나, 왼쪽 안내 창의 폭을 줄여 주세요.
