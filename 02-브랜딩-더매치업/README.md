## 작업 과정

1. **컨셉 시트:** 타깃 페르소나, 컨셉, 브랜드 이름, 슬로건, 컬러 정의 → [`컨셉시트.txt`](https://github.com/fivcomet/Elice-AX/blob/main/02-%EB%B8%8C%EB%9E%9C%EB%94%A9-%EB%8D%94%EB%A7%A4%EC%B9%98%EC%97%85/%EC%BB%A8%EC%85%89%EC%8B%9C%ED%8A%B8.txt)
2. **무드보드:** 브랜드 분위기를 4컷 이미지로 생성 → [`mood board prompt.txt`](https://github.com/fivcomet/Elice-AX/blob/main/02-%EB%B8%8C%EB%9E%9C%EB%94%A9-%EB%8D%94%EB%A7%A4%EC%B9%98%EC%97%85/mood%20board%20prompt.txt)
3. **로고**
4. **SNS 홍보 이미지:** 인스타그램 캐러셀 3컷 → [`sns 이미지 프롬프트.txt`](https://github.com/fivcomet/Elice-AX/blob/main/02-%EB%B8%8C%EB%9E%9C%EB%94%A9-%EB%8D%94%EB%A7%A4%EC%B9%98%EC%97%85/sns%20%EC%9D%B4%EB%AF%B8%EC%A7%80%20%ED%94%84%EB%A1%AC%ED%94%84%ED%8A%B8.txt)
5. **캡션:** 인스타그램 게시물 문구 → [`캡션 작성 프롬프트.txt`](https://github.com/fivcomet/Elice-AX/blob/main/02-%EB%B8%8C%EB%9E%9C%EB%94%A9-%EB%8D%94%EB%A7%A4%EC%B9%98%EC%97%85/%EC%BA%A1%EC%85%98%20%EC%9E%91%EC%84%B1%20%ED%94%84%EB%A1%AC%ED%94%84%ED%8A%B8.txt) / [`캡션.txt`](https://github.com/fivcomet/Elice-AX/blob/main/02-%EB%B8%8C%EB%9E%9C%EB%94%A9-%EB%8D%94%EB%A7%A4%EC%B9%98%EC%97%85/%EC%BA%A1%EC%85%98.txt)
