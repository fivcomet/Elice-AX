# 따릉이 수요 예측 모델 — 실행 방법

## 1. 준비물

| 파일/프로그램 | 설명 |
|---|---|
| `bike.py` | 분석 + 모델 코드가 들어있는 파이썬 파일 |
| `따릉이_대여량.csv` | 원본 데이터 (bike.py와 같은 폴더에 있어야 합니다) |
| Python 3 | 파이썬 실행 프로그램 |

## 2. 필요한 라이브러리 설치 (처음 한 번만)

터미널(명령창)에서 아래 명령을 실행합니다.

```bash
pip install pandas numpy matplotlib scikit-learn
```

| 라이브러리 | 하는 일 |
|---|---|
| pandas | CSV 파일을 표로 읽고 가공 |
| numpy | 로그 등 숫자 계산 |
| matplotlib | 그래프 그리기 |
| scikit-learn | 데이터 분할, 선형회귀·랜덤포레스트, 성능 평가 |

## 3. 실행하기

`bike.py`와 `따릉이_대여량.csv`를 같은 폴더에 넣고, 터미널에서 그 폴더로 이동한 뒤 실행합니다.

```bash
cd 파일을-넣은-폴더
python bike.py
```

윈도우에서 `python`이 안 되면 `py bike.py`, 맥에서는 `python3 bike.py`로 실행하세요.

## 4. 실행 결과

### 터미널에 출력되는 내용 (위에서부터 순서대로)
1. 데이터 크기 (8,760행 × 14열)
2. 열별 자료형 표 (숫자/글자)
3. 시간대별 평균 대여건수 텍스트 그래프
4. 비 유무·강수량 구간·계절·휴일 분석 결과
5. 대여건수 0인 줄 분석
6. 상관계수 표
7. 원-핫 인코딩 후 열 목록
8. **모델 성능: R², MAE** (선형회귀 전체 특성 / 기온만 / 랜덤포레스트)
9. 처음 보는 날짜(매달 22일 이후)로 시험한 결과

### 새로 생기는 파일
| 파일 | 내용 |
|---|---|
| `bike_hour.png` | 시간대별 평균 대여건수 막대그래프 |
| `bike_corr.png` | 대여건수와 숫자 열들의 상관계수 그래프 |

## 5. 자주 하는 실수

- **`FileNotFoundError`** → CSV 파일이 bike.py와 같은 폴더에 없는 경우입니다. 두 파일을 같은 폴더에 넣으세요.
- **그래프의 한글이 네모로 깨짐** → 맑은 고딕·애플고딕·나눔고딕 중 설치된 폰트가 없는 환경입니다. 한글 폰트를 하나 설치하세요.
- **`ModuleNotFoundError: No module named 'sklearn'`** → 2번의 라이브러리 설치가 안 된 것입니다.
