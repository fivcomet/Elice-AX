# 서울 아파트 가격 예측 모델 — 다른 PC에서 실행하는 방법 (초보자용)

**파일 2개**만 있으면 됩니다. 순서대로 따라 하면 됩니다.

## 준비물

깃허브의 `08-seoul-apt-price` 폴더에서 아래 두 파일을 받아 **같은 폴더**에 넣으세요.

| 파일 | 역할 |
|---|---|
| `rf_model.joblib` | 학습이 끝난 모델 본체 (약 11MB) |
| `09_load_and_predict.py` | 모델을 불러와 예측하는 코드 (한 줄씩 주석 있음) |

모델을 직접 다시 만들고 싶으면 `서울_아파트_실거래가_2025_clean.csv`와 `08_save_model.py`도 같은 폴더에 받아 두세요.

## 1단계. 파이썬 설치 (이미 있으면 건너뛰기)

1. https://www.python.org/downloads/ 에서 파이썬 3 다운로드 후 설치
2. **윈도우는 설치 첫 화면에서 "Add python.exe to PATH" 반드시 체크**
3. 설치 확인: 터미널(윈도우: 명령 프롬프트, 맥: 터미널)을 열고
   ```
   python --version
   ```
   `Python 3.x`가 나오면 성공. 안 나오면 `py --version`도 시도해 보세요.

## 2단계. 필요한 라이브러리 설치

터미널에서:
```
pip install scikit-learn==1.9.1 pandas joblib
```
- `scikit-learn` : 모델을 만들고 돌리는 도구. 모델 파일을 **1.9.1 버전으로 만들었기 때문에 같은 버전**을 설치해야 안전하게 열립니다.
- `pandas` : 표 데이터를 다루는 도구.
- 다른 버전을 쓰고 있다면 3단계에서 `08_save_model.py`를 먼저 실행해 모델을 내 컴퓨터에서 새로 만들면 됩니다.

## 3단계. 실행

터미널에서 파일을 넣은 폴더로 이동한 뒤:
```
cd 파일을-넣은-폴더
python 09_load_and_predict.py
```

정상이면 이렇게 나옵니다:
```
모델 정보: 학습일 2026-11-05, sklearn 1.9.1, 테스트 R² 0.9240, MAE 11,290만원
자치구명 법정동명  전용면적  층  건축년도  예측금액_만원
 강남구  대치동  84.9 10  2015     402600.0
 도봉구   창동  59.9  3  2000      54000.0
```
→ 강남구 대치동 84.9㎡ 아파트는 **약 40.3억**, 도봉구 창동 59.9㎡는 **약 5.4억**으로 예측했다는 뜻.

**모델을 직접 다시 만들 때:** `python 08_save_model.py`를 먼저 실행하면 같은 폴더에 `rf_model.joblib`가 새로 만들어집니다 (1~2분).

## 4단계. 내가 원하는 아파트 예측하기

`09_load_and_predict.py`를 메모장 등으로 열어서 이 부분의 값을 바꾸면 됩니다:
```python
{"자치구명": "강남구", "법정동명": "대치동", "전용면적": 84.9, "층": 10, "건축년도": 2015,
 "계약일": "20260101", "신고구분": "중개거래"},
```
- 자치구명: 서울 25개 자치구 (예: 송파구, 마포구)
- 법정동명: 그 구에 있는 법정동 (예: 송파구 잠실동, 마포구 아현동). 학습 데이터에 없는 동을 넣으면 경고가 나옵니다.
- 계약일: `YYYYMMDD` 형식
- 여러 개 예측하려면 같은 모양의 줄을 계속 추가하면 됩니다.

## 자주 나는 오류 해결

| 오류 메시지 | 뜻 | 해결 |
|---|---|---|
| `'python'은(는) 내부 또는 외부 명령...` | 파이썬이 설치 안 됨/경로 문제 | 1단계 재설치(윈도우 PATH 체크!), `py`로도 시도 |
| `ModuleNotFoundError: No module named 'sklearn'` | 라이브러리 미설치 | 2단계의 pip install 실행 |
| `InconsistentVersionWarning` | 모델 파일을 만든 sklearn 버전(1.9.1)과 지금 버전이 다름 | `pip install scikit-learn==1.9.1` 또는 `08_save_model.py`로 모델 새로 만들기 |
| `FileNotFoundError: ... rf_model.joblib` | 모델 파일이 같은 폴더에 없음 | 두 파일을 같은 폴더에 넣었는지 확인 |
| `FileNotFoundError: ... _clean.csv` | 08번 실행 시 데이터 파일이 같은 폴더에 없음 | 정제 CSV를 같은 폴더에 넣었는지 확인 |
