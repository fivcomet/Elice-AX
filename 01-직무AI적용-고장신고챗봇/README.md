# 01. 고장 신고 1차 응대 AI 챗봇 도입 제안

엘리스 AX 과정 「내 직무에서 AI 적용하기」 실습 결과물입니다.
고장 신고를 전화로 받아 증상 분류, 원격 조치 안내, 방문 판단, 기록까지 담당자가 모두 처리하는 업무에 AI 챗봇을 도입하는 방안을 조사하고 제안했습니다.

## 핵심 내용

- **방향:** 상담원 대체가 아니라, 반복 안내와 접수 기록은 AI가 맡고 판단과 응대는 사람이 맡는 구조
- **이관 기준:** 안전 증상(연기·발열·누전), 불만 표현, 반복 고장, 2회 미해결, 상담원 요청 건은 사람에게 자동 이관
- **추진 단계:** 2주 현황 측정 → 3개월 파일럿(채팅 채널, 상위 반복 증상 20개) → 확대
- **근거:** 국내외 도입 사례, 업계 통계, 솔루션 가격 문서 조사 (내부 수치는 [가정]으로 표시)
